# St. Joseph Youth Sports Foundation

Next.js conversion of **SJ Youth Sports – Version 4**.

## Stack

- Next.js App Router
- React 19
- TypeScript
- Tailwind CSS 4
- Montserrat via `next/font`

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — local development
- `npm run build` — production build
- `npm start` — serve the production build

## Project notes

- Page UI lives in `src/components/HomePage.tsx` (client component with scroll header / parallax).
- Images are in `public/images/`.
- Brand colors: navy `#00214D`, gold `#E7BA22`, field green accents.
